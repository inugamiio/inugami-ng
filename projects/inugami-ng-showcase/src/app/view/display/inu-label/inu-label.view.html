Default HTTP API

The default implementation attempts to retrieve labels via an HTTP call to the URL /api/label. Once the response is received, it is cached for 1 hour.

InuLabelService

This service acts as the single source of truth for all application strings.

Key Features:
Decoupling
Implemented via the INU_LABEL_SERVICE Injection Token.
Eager Loading
Triggered at startup via provideEnvironmentInitializer to ensure labels are available as soon as possible.
Smart Caching
Integrated with InuCacheServices using a 1-hour TTL (Time To Live) to minimize redundant network traffic.
Language Detection
Automatically parses window.navigator.language. If the detected language is not found in the API response, it fallbacks to EN.

The IInuLabelService is configured as a global provider within the appConfig. It follows a decoupled architecture using an Injection Token to allow for easy swapping of implementations (e.g., for testing or different environments).

The service is registered using a custom provider function provideInuLabelService(). This function links the INU_LABEL_SERVICE token to the InuLabelService class implementation.

To prevent delays when components first request a label, the service is eagerly instantiated during the application's bootstrap phase using provideEnvironmentInitializer.

  • Mechanism: The initializer explicitly calls inject(INU_LABEL_SERVICE).
  • Purpose: This triggers the service's constructor immediately, which in turn starts the HTTP fetch for the labels (or retrieves them from cache) before the UI is fully rendered.
