Inugami-NG : inu-panel

The InuProgress component is a lightweight, highly flexible, and performant container that supports collapsible behavior, custom styling, and advanced content projection using a template registry system. It features smooth, frame-budgeted native animations without relying on the @angular/animations module.

Properties

Property Type Default value Description duration number 500 The animation duration in milliseconds for the expand/collapse transition. icon string undefined The name of the icon to display in the panel header. title string undefined A static string text for the panel title. titleKey string undefined The localization key passed to the centralized label management system (InuLabel). styleClass string undefined Custom CSS classes to append to the host component element. collapsible boolean true Determines whether the panel can be expanded or collapsed by the user. collapsed string undefined Sets the initial state of the panel (true for closed, false for open).
