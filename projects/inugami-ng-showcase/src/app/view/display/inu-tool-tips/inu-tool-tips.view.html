Inugami-NG : inu-tool-tips

The InuToolTips component is a versatile, contextual help system designed to display additional information—either raw text or complex custom templates—relative to a trigger element.
Key Features
Template Support
Seamlessly injects rich HTML layouts using the InuTemplateRegistryService.
Expert Mode (Ctrl-Hover)
Supports conditional triggering. Users can reveal tooltips simply by holding the Ctrl key while hovering over the component.
Auto-dismiss Logic
Integrated timer management for automatic closing after a specific duration.
