Inugami-NG : inu-progress

The inu-progress component is a high-performance, precision-engineered linear progress bar container built for the Inugami-NG framework. It features native, frame-budgeted animation sequences, sub-pixel text color splitting with no layout positioning shifts, and fully concurrent animation sequence tracking to prevent stuttering or "jump-back" visual glitches.
