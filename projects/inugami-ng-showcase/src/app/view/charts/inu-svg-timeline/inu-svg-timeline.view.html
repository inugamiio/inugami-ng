Inugami-NG : inu-svg-timeline

The inu-svg-timeline component is a robust, interactive, and high-performance time-series visualization tool built for Angular. It supports lazy-loaded data, smooth zooming, pan/selection modes, and seamless integration with Angular forms.

Key Features
Dynamic SVG Rendering
High-performance vector rendering with scoped management.Asynchronous Lazy Loading: Optimized via the BucketTimedLoader service to fetch data based on the current viewport and resolution.
Interactive Modes
  • Pan: Navigate through time (Ctrl + Drag).
  • Zoom & Reset: Smooth zooming via the mouse wheel, with an instant reset back to the original time interval using a simple mouse wheel double-click.
  • Selection: Precise range selection (Drag).
Responsive Design
Built-in ResizeObserver ensures the component adapts perfectly to container size changes.
Angular Signal Forms Integration
Full support for the FormValueControl interface, allowing bidirectional model synchronization.

Model

The component uses a unified data model designed to describe temporally ordered data hierarchically:

BucketTimed
Represents a time bucket container. The component fetches a list of these objects (e.g., success, warning, and error levels act as buckets in our implementation).
ResourceTimed
Each bucket can contain multiple resources, allowing you to distinguish between different entities or error codes within the same category.
PointTimed
The leaf nodes containing the actual measurements. Each point consists of a numerical value associated with its specific timestamp.

Lazy loading

A recurring challenge in data visualization is managing large volumes of data. To keep the SVG rendering optimized and performant, the inu-svg-timeline component is designed around a fixed resolution approach.

  • Optimized Rendering

    By relying on a fixed resolution per view, the DOM remains lightweight and responsive.

  • Asynchronous Lazy Loading

    Data fetching is fully delegated via lazy loading, passing both the precise time interval (from / until) and the active resolution to load only the required data slice dynamically.

Data Rendering

The component is designed by cleanly separating its global state and lifecycle management from data rendering. This architecture supports multiple built-in renderers—such as bar charts and line charts—while also allowing developers to implement custom, domain-specific renderers via the TimeLineRenderer interface.

The rendering type is defined directly via the renderer attribute of the component and can be changed dynamically. To ensure smooth transitions and correct visualization, all custom renderer implementations must adhere to the following lifecycle contract:

init
Initializes the renderer layout. The main component provides the SVG graph node, the available dimensions for rendering, and the resolution.
updateContext
Called after data is received to specify the rendering area dimensions and resolution. This method is also invoked whenever the display area is resized.
isCumulative
Returns a boolean indicating whether the renderer is cumulative, which is required to correctly compute maximum value boundaries.
setMaxValue
Sets the maximum data value to scale and normalize the visualization properly.
updateValues
Passes the fetched dataset from the main component into the renderer.
destroy
Invoked by the parent component during renderer switches to allow the current renderer to animate out and properly clean up its SVG DOM nodes.
Rendering the data is a delicate task, and a solid understanding of SVG is essential to master custom renderer implementations and visual customizations. Each instance of the inu-svg-timeline component must have its own dedicated renderer instance. Renderer definitions must be handled via a factory function that creates a new instance for each component.

SVG Service

While low-level rendering involves directly manipulating SVG DOM nodes for optimal performance, several helper utilities are provided to simplify element design and construction:

SVG_ANIMATION
Helps manage SVG transitions and animations.
SVG_BUILDER
Simplifies programmatic creation and structuring of SVG elements.
SVG_TRANSFORM
Eases matrix and coordinate transformations.
SVG_MATH
To assist with trigonometric calculations and coordinate positioning required for advanced visual representations (such as angular gauges, polar charts, or specialized curves), the SVG_MATH utility provides a dedicated collection of trigonometric helper methods.

Various TypeScript models and interfaces are provided out-of-the-box to easily interact with the SVG service APIs and structure your data payloads seamlessly.
