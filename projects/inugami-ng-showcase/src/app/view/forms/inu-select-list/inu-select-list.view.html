Inugami-NG : inu-select-list

The inu-select-list component is a flexible, signal-driven selection list designed to handle both simple list rendering and complex asynchronous (lazy) data streaming. It seamlessly integrates with forms signals.

Example

The inu-select-list component uses InuSelectItem objects to display its list of items. By default, the title property of the InuSelectItem is used to render each item.

However, it can be highly useful to override this behavior. To do so, you can define a template named item directly within the component. Once defined, your custom template will be used to handle the rendering of each individual element.

By default, inu-select-list handles primitive values. However, when dealing with complex datasets or enterprise APIs, your form model might only store an ID while your list needs to display full object details. To bridge this gap without cluttering your forms, the component provides two powerful hooks: matcher and extractor

Example lazy

In more complex scenarios, fetching a list of values might require a server-side request. For these use cases, you should adopt the lazy loading strategy. In this mode, you must provide a method that the component will use to load the data.

In this example, the API call is simulated by generating an observable using the ObservableSubscriber class from inugami-ng. This class allows us to directly manipulate the internal subscriber to push data through the observer and notify the component.

To use it, simply pass this method to the component in your template
