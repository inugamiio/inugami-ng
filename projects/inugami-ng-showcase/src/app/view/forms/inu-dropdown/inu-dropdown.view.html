Inugami-NG : inu-dropdown

The inu-dropdown component is an extended, highly configurable dropdown menu designed for seamless integration with Angular Signals Forms (FormValueControl). It wraps an InuSelectList and supports single or multiple selection, filtering, pagination, on-demand loading (lazy loading), and graphic customization via templates.
