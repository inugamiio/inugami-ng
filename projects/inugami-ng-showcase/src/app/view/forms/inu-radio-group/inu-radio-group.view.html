Inugami-NG : inu-radio-group

The inu-radio-group component allows defining radio buttons within forms. This component uses a list of select items to define the different possible values, thus providing a straightforward implementation of this type of component in your forms.

Example

Model

The InuSelectItem interface allows defining an object that can be selected. This interface is designed for use within forms. The concept of a select item is highly generic and can therefore be applied to radio buttons, checkboxes, dropdown lists, etc.

Vertical example

Required example

Mandatory field logic is handled directly by the Signal form. Therefore, there is no need to define a required attribute on the component to enforce validation.

Disabled example

Similarly to mandatory fields, disabled states are also defined via the Signal form.
