Inugami-NG : inu-multi-states

The inu-multi-states component is a flexible, highly customizable segment control designed to handle multi-selection or single-selection across multiple options. It fully integrates with Angular Signals and the FormValueControl API

Example default

With custom styleclass

Custom colors can be defined for individual items using the styleClass property inside the InuSelectItem object.

Single select

Functions like a radio group or toggle switch but keeps the segmented layout. Selecting a state unselects any active state. Clicking an already selected state will deselect it (returning null).

With tempalte

Using InuTemplateRegistryService, custom icons or markup can be integrated inside the state components.
