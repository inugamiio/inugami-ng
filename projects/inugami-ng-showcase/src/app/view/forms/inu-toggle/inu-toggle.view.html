Inugami-NG : inu-toggle

The InuToggle component is a lightweight, fully accessible standalone binary switch designed for seamless integration with Signals Forms . It acts as a visual alternative to a native checkbox, supporting localization, thematic styling variations, disabled states, and full keyboard navigation.
